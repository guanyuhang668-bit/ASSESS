# Supplementary materials

Study materials and de-identified data used in the classroom evaluation of ASSESS.

| File | Content |
|---|---|
| `indicator.xlsx` | Rubric catalog: the primary and secondary indicators of the four diagram types (use case, class, sequence, swimlane), each with the detailed description of what the secondary indicator checks. |
| `Campus_Fun_Run_and_ATM_System_Assignments.docx` | The two UML modeling assignments used in the course (Campus Fun Run app, Smart ATM self-service cash withdrawal), with the diagram types and modeling constraints given to students. |
| `survey_instrument.xlsx` | Student questionnaire: the questions grouped into six dimensions, with the aggregate number of respondents per option. |
| `Classes_1-2_Grading_Data_English.xlsx` | De-identified score matrix for classes 1–2: one column block per submitted diagram, holding the rubric-level scores given by human raters and by each evaluated LLM (GPT-4o, DeepSeek V3, Gemini 3 Flash, Qwen 3 Max). |
| `Classes_3-4_Grading_Data_English.xlsx` | De-identified score matrix for classes 3–4 in the same layout (human raters and GPT-4o, DeepSeek V3, Qwen 3 Max). |

The score matrices contain rubric-level scores per anonymous column block only. Student names, student identifiers, submitted diagrams, and identifiable course records are not included.
